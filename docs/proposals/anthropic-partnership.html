A verified path for authorized security audits on Claude

Kase asks Anthropic to work with us as a verified security partner, so that authorized, scope-controlled audits can run on Claude Opus 5.5 and Claude Fable 5.1 without being blocked.

Summary

We'd rather fix this properly than work around it

Kase is an AI QA and security audit platform. Today, safeguards on Claude Opus 5.5 and Claude Fable 5.1 flag a share of our legitimate audit runs, so we've had to pin production to Claude Opus 4.8.

That isn't a lasting answer, for us or for Anthropic. We'd rather show Anthropic exactly how Kase controls its use of Claude, and agree on a vetted way forward.

We're not asking for safeguards to be removed. We're asking for a verified channel, scoped to work our customers have authorized, with an audit trail Anthropic can inspect.

About Kase

Audits that link what's seen from outside to the code behind it

Kase audits a running system and its source code together. It links each externally observed defect to the exact code that causes it, then turns the result into an automated release decision.

Black box

Scoped recon, browser testing and API checks against a target the customer owns.

White box

Read-only static analysis of the customer's repository. No install, no build, no code execution.

Correlation

Controls in place

The model never touches a target directly

Every action Claude proposes passes deterministic controls that it can't override.

ControlWhat it does
Authorization attestationA named person attests authorization before a project exists. It expires after 12 months and is renewed when the target changes.
Scope validatorEvery outbound request is checked against an exact host allowlist. Bare TLDs and * are rejected, private ranges are denied, and redirects and discovered URLs are re-checked.
No agent egressThe Claude worker reaches only the LLM provider. Only the Tool Runner issues requests, after validation.
Non-destructive by defaultDELETE, unsafe writes, intrusive templates and load tests are blocked unless separately attested.
Methodology guardThe agent follows a fixed, versioned audit methodology, and its capability calls are schema-validated.
Read-only code analysisNo install, build or code execution. The worker runs non-root with a seccomp profile.
Rate limits and budgetsPer-host request limits apply across all audits, plus a request budget per audit.
Immutable audit trailAttestations, scope denials, agent scope-change requests and evidence access are logged and kept indefinitely.
Confidential findingsFindings go only to the customer. Nothing reaches third parties without the customer acting.

Our proposals

Five specific asks

  1. 01

    Verified security-org enrollment

    Enroll Kase's organization in Anthropic's verified security or cyber-defense access program, or tell us the closest equivalent. We'll complete any KYC, use-case review or security questionnaire Anthropic needs.

  2. 02

    Adjustments scoped to authorized audits

    Change safeguard behavior only for traffic from Kase's audit worker, in a dedicated workspace or key, and never across our whole organization. Every request there is tied to an attested target and a scope policy.

  3. 03

    A false-positive feedback loop

    Give us a named contact or channel for redacted examples of flagged runs that should have passed, with request IDs, so Anthropic can tune its classifiers. We'll send them on a regular schedule.

  4. 04

    Structured context on each request

    Agree on metadata Kase attaches to every call: attestation ID, target hosts in scope, audit type and a non-destructive flag. Safeguards could then tell an authorized audit apart from an attack.

  5. 05

    Design partner for security tooling

    Kase would test new models and safeguard changes before release on realistic, authorized security workloads, and report regressions both ways: harmful use that gets through, and legitimate work that gets blocked.

In return

What Kase commits to

  • Follow Anthropic's Usage Policy, and shut off any customer who misuses Kase for unauthorized testing.
  • Keep the controls above enforced at the infrastructure level, and tell Anthropic before we weaken any of them.
  • Share a design review of our scope validator and agent isolation, under NDA if Anthropic wants one.
  • Give Anthropic attestation and audit-trail records for any request it asks about.
  • Report suspected misuse of Kase to Anthropic promptly.
