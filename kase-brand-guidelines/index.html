The visual system gives verified state, severity, and operational context a deliberate order. Decoration never competes with evidence.

Application

Professional by restraint.

Use

+ Dark surfaces with a clear reading order
+ Teal for confirmation and primary action
+ Source-like mono for technical references
+ Direct language that names evidence

Avoid

- Multiple accent colors competing for focus
- Decorative gradients or ambient glow
- Visual severity without an evidence basis
- Alarmist language or vague assurance
